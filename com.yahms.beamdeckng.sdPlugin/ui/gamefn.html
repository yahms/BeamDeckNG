"via keyboard" functions press the real key (shown on the button), held for as long as you hold the button, so the game does exactly what that key does (menus, walking, the free camera, driving; Insert rewinds while held). The game window must be the focused window. "via MCP" functions use the game's own actions and work without focus: Back opens the pause menu in the game and steps back through menus, Accept selects, the arrows move through menus, walk on foot and fly the free camera.

Next / previous camera step through every camera the vehicle has (driver, hood, chase, orbit, external, top...). Tick the box to follow the game's own camera list instead, which only includes the cameras enabled in its camera settings.

Action name and key text are only used with "Custom game action": any action from the game's Controls menu, fired directly (no key binding needed).
