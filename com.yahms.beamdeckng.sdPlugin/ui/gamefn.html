Input (arrows, Repair, Back, Accept): "Real keyboard key" presses the arrow / Insert / Esc / Enter key, held for as long as you hold the button, so the game does exactly what that key does (menus, walking, the free camera, driving; Insert rewinds while held). The game window must be the focused window. "The game's action" works without focus: Back opens the pause menu in the game and steps back through menus, Accept selects. By default the arrows and Repair send the real key and Back / Accept use the game's action.

Next / previous camera step through every camera the vehicle has (driver, hood, chase, orbit, external, top...). Tick the box to follow the game's own camera list instead, which only includes the cameras enabled in its camera settings.

Action name and key text are only used with "Custom game action": any action from the game's Controls menu, fired directly (no key binding needed).
