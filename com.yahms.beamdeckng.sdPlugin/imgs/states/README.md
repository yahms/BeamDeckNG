# Your own key images (optional)

Button icons are read from your own copy of BeamNG.drive while the plugin runs, so none ship here.
To use your own image for a state, put a 144x144 PNG at `<key>/<state>.png` in this folder
(and `<key>/<state>_flash.png` for the flash frame), e.g. `diff/locked.png`, `ignition/running.png`.
Your images win over the game's icons. Keys and states are listed in `src/glyphmap.ts`.
